# v0.7.2 — 修正工具範圍與執行邊界

**發布日期**：2026-07-06

**一句話結論**：這版修正兩份指令的適用範圍，並讓對話型工具版本在遇到本機工具或沙盒時不再過度介入。

---

## 一、這版對你有什麼用

這版主要修正指令在不同工具環境下的行為邊界。

- 對話型工具版本現在只在任務真的涉及檔案、程序、本機路徑、外部工具或可保存改動時，才啟動執行面判斷。
- 純對話、純分析、短答與創作任務不會因本機工具或沙盒規則而增加不必要步驟。
- 當 AI 需要在沙盒與本機原生工具之間選擇時，指令要求先確認路徑與環境差異，不把沙盒路徑誤當成本機真實路徑。
- 代理式工具版本的適用範圍已對齊 OpenAI Codex、Claude Code、Antigravity CLI、Cursor，以及其他會讀檔、改檔或執行工具的 AI agent。
- 公開入口同步按工具名稱導引用戶，避免把對話工具與代理式工具混用。

## 二、你是否需要更新

- **建議更新**：正在使用對話型工具版本，且你的 AI 工具可能同時看到沙盒、本機路徑、本機工具或可保存檔案改動。
- **建議更新**：正在使用 OpenAI Codex、Claude Code、Antigravity CLI、Cursor 或其他代理式 AI 工具。
- **建議更新**：曾因不知道應貼 01 還是 02，而把指令放到不合適工具中的用戶。
- **可暫不更新**：只在純聊天工具中做低風險短答，且不會碰檔案、命令、本機工具或機密資料。

## 三、怎樣使用

1. 使用 ChatGPT、Claude、Claude Cowork 時，複製 `prompts/01-claude-cowork-meta-instruction/prompt.md`。
2. 使用 OpenAI Codex、Claude Code、Antigravity CLI、Cursor 時，複製 `prompts/02-claude-code-meta-instruction/prompt.md`。
3. 工具不在上述名稱中時，只聊天、寫作、整理資料用 01；會碰檔案、命令、機密或發布流程用 02。

## 四、已知限制

- 早期發布說明保留當時語境，可能仍出現舊工具分類說法；目前使用時以 v0.7.2 的主 README 與兩份 prompt README 為準。
- 未列出的工具仍需要按用途判斷：只聊天用 01；會碰檔案、命令、機密或發布流程用 02。
