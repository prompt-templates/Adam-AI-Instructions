# v0.7.1 — AI Agent 通用版與發布整理

**發布日期**：2026-05-24

**一句話結論**：這版把 prompt 02 整理成真正可公開使用的 AI Agent 通用版，並清走過密、混亂的舊發布。

---

## 一、這版對你有什麼用

這版的重點不是新增很多規則，而是讓你更容易選對、讀懂、直接使用。

- prompt 02 不再像單一工具專用版，而是適合會讀檔、改檔、執行工具或處理機密的 AI Agent。
- prompt 02 保留 01 的穩定基底，再補上機密處理、平台檔案安全、代理式工作流三組附加規則。
- 手機開啟 prompt 02 互動指南時，頁首與正文不再被裁切。
- GitHub Releases 清理後，讀者不會被過多小版本與錯方向版本干擾。

## 二、你是否需要更新

- **建議更新**：你正在使用 prompt 02，或希望 AI 在讀檔、改檔、執行工具、處理 `.env` / credentials 時更穩定。
- **可暫不更新**：你只使用 prompt 01，且目前主要是純對話、寫作、分析或輕量任務。

## 三、怎樣使用

1. 若你需要完整代理式工具邊界，使用 `prompts/02-claude-code-meta-instruction/prompt.md`。
2. 若你只需要通用對話與治理基底，繼續使用 `prompts/01-claude-cowork-meta-instruction/prompt.md`。
3. 若你不確定選哪個，先看 prompt 02 的互動指南，再按「01 vs 02 怎麼選」判斷。

## 四、已知限制

- 這版主要整理 prompt 02 與發布呈現；prompt 01 的核心基底仍沿用 v0.7.0 的 12 節結構。
- GitHub Releases 中 v0.7.0 以前的保留版本仍是歷史紀錄，部分舊頁面會保留當時的舊命名。
