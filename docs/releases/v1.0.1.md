# v1.0.1 — 先讀齊核心真源，才定基線

**發布日期**：2026-08-23

**一句話結論**：複雜任務不再只說「用了哪些來源」；需要定基線、比較、研究、報告、治理或高風險交付時，AI 要先確認核心權威來源是否覆蓋足夠。

---

## 一、這版對你有什麼用

這版補強 v1.0.0 的層級對焦，針對一個常見風險：AI 讀了搜尋結果、摘要或舊交接，便太早下結論和開始執行。

- 長任務會先分清本輪結論或行動依賴哪些核心權威來源。
- 搜尋結果、檔頭、索引、摘要和舊交接只能用來定位真源，不能當成基線證據。
- 核心真源未讀齊或互相衝突時，AI 要先補讀、收窄範圍或請你裁決，不得假裝已可定基線。

## 二、你是否需要更新

- **建議更新**：你常用 AI agent 做研究、報告、文件整理、多檔修改、規則治理、產品交付或高風險計劃，並想減少「未讀齊便盲猜」的情況。
- **可暫不更新**：你只用它做短答、簡單創作、單一小修或低風險查詢，而且目前沒有遇到來源覆蓋不足的問題。

## 三、怎樣使用

1. 打開你目前用來保存專案或工作區長期 AI 指令的位置。
2. 用 v1.0.1 完整指令取代舊版，選繁中或英文其一，不要兩份同時貼入同一位置。
3. 開一個新任務。若任務需要定基線、比較或研究判斷，你應看到 AI 先交代核心真源覆蓋是否足夠。

## 四、已知限制

- 這版不能保證所有 AI 工具都百分百遵守；工具本身的權限、沙盒、版本控制和確認機制仍然重要。
- 本次更新是行為規則與公開說明的本地驗收；尚未提供跨模型或真實使用統計證據。
