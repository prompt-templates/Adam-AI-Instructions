# v1.0.0 — 先對焦，再計劃

**發布日期**：2026-08-17

**一句話結論**：長任務先分清真正目標、本輪產出和停止條件，才決定是否需要全圖計劃；答案結尾的 `🚀 下一步` 也只在真正有用時出現。

---

## 一、這版對你有什麼用

這版針對長任務常見的失焦問題：AI 技術上做了很多步，但沒有推近使用者真正想要的成果。

- 長任務、多檔、多階段、研究／報告、產品交付或高風險治理，會先顯示 `🎯 層級對焦`，分清最終成果、本輪實際產出、真源、範圍外項和停止條件。
- AI 只有在對焦結果「對準」時，才進入全圖計劃或開始執行；若「失焦」，會先收窄目標或證據；若「受阻」，會直接說明缺口。
- `🚀 下一步` 不再為了格式而出現。只有仍有具體、低摩擦、與目標直接相關的後續動作時，才列出清楚行動。

## 二、你是否需要更新

- **建議更新**：你常用 AI agent 處理工作文件、長任務、研究、報告、產品交付、程式修改或治理審閱，並想減少「忙了很久但方向不對」的情況。
- **可暫不更新**：你只用它做短答、簡單創作或單步低風險工作，而且目前沒有遇到失焦或下一步建議過多的問題。

## 三、怎樣使用

1. 打開你目前用來保存專案或工作區長期 AI 指令的位置。
2. 用 v1.0.0 完整指令取代舊版，選繁中或英文其一，不要兩份同時貼入同一位置。
3. 開一個新任務。若任務較長或容易失焦，你應看到 AI 用 `🎯 層級對焦` 先說明是否對準。

## 四、已知限制

- 這版不能保證所有 AI 工具都百分百遵守；工具本身的權限、沙盒、版本控制和確認機制仍然重要。
- 本次更新是行為規則與公開說明的本地驗收；尚未提供跨模型或真實使用統計證據。
