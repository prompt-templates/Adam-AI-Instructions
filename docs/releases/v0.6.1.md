# v0.6.1 — Hotfix：安裝指引改善（非技術讀者友善 + 補 Codex 路徑）

**發布日期**：2026-05-17
**主旨**：改善 v0.6.0 release 後安裝指引的可讀性。v0.6.0 root README 第四節 Claude Code 安裝只一句路徑、完全缺 OpenAI Codex AGENTS.md 路徑；02 README 第五節雖有 step-by-step 但 Codex 與其他 AGENTS.md agent 混為一段、未說明如何確認指令已生效。本 hotfix 將安裝指引重寫為非技術讀者友善的步驟化版本，並補入官方文件記載的進階設定。

---

## 一、這次更新解決什麼

### 痛點：安裝指引對非技術讀者不夠友善

**v0.6.0 已做嘅安裝指引**：

- root README 第四節列出 Claude Cowork / Claude Code / ChatGPT / 其他工具四項
- 02 README 第五節有 Claude Code / Codex+其他 AGENTS.md agent 合併段 / Cowork / ChatGPT 四段 step-by-step

**v0.6.0 仲未修嘅 bug**：

- root README 第四節 Claude Code 只一句「`~/.claude/CLAUDE.md` 或項目根目錄 `CLAUDE.md`」，非技術讀者見到反斜線同 tilde 符號無從入手。
- root README 第四節完全缺 OpenAI Codex 全域 AGENTS.md 安裝路徑。
- 02 README 第五節將 OpenAI Codex 與 Amp / Cursor / Factory / Google Jules 合為一段，hardcode 全域路徑為 `~/.codex/AGENTS.md`，誤導讀者以為其他 AGENTS.md agent 都用同一路徑。
- 兩個 README 皆缺「如何確認指令已生效」段落，用戶套完 prompt 不知有冇成功。
- 環境變數覆蓋（`CLAUDE_CONFIG_DIR` / `CODEX_HOME`）與 OpenAI Codex `AGENTS.override.md` 覆寫優先級兩項官方文件明確記載的進階設定全部漏寫。

### 修正

**root README 第四節**

- Claude Code、OpenAI Codex 改為步驟化說明，每個工具列出全域路徑（macOS / Linux + Windows 兩個版本）、單一項目路徑、新建資料夾與檔案處理、儲存後重新開啟工具即生效。
- 新增「其他 AGENTS.md 標準 agent」獨立段落（Amp / Cursor / Factory / Google Jules 等），釐清項目層級用 `AGENTS.md` 為跨工具通用標準、全域路徑視工具而異要查官方文件。
- Claude Cowork 與 ChatGPT 段落 wording 統一為步驟化說明。
- 新增「進階提示」blockquote 段落，覆蓋環境變數覆蓋（`CLAUDE_CONFIG_DIR` / `CODEX_HOME`）與 OpenAI Codex `AGENTS.override.md` 覆寫優先級兩項。

**02 README 第五節**

- 將原本 Codex 與其他 AGENTS.md agent 合併段落拆分為兩段：OpenAI Codex 獨立，Amp / Cursor / Factory / Google Jules 另一段。
- Claude Code 與 Codex 各列「全域安裝」「單一項目安裝」兩個明確子段，每個子段提供 5 步流程。
- 新增「確認是否生效」段，提供具體驗證任務（多檔修改任務觸發五區段全圖即代表指令已載入）。
- 新增「進階提示」段補入環境變數覆蓋、Codex 覆寫優先級、跨平台範圍三項。

**root README 第六節**

- 最近更新表加 v0.6.1 行。

## 二、你會在何時感受到變化

- 開 root README 第四節，每個工具的安裝步驟有清晰的中文書面語列點，免直接面對 `~/.claude/CLAUDE.md` 路徑串而不知如何下手。
- Claude Code 用戶可按 5 步流程完成全域或單一項目安裝；資料夾不存在亦明確說明自行新建。
- OpenAI Codex 用戶不再缺安裝路徑（v0.6.0 root README 完全缺漏），可直接照步驟貼入 `~/.codex/AGENTS.md` 或項目根目錄 `AGENTS.md`。
- AGENTS.md 標準 agent 用戶清楚知道：項目層級用 `AGENTS.md` 是跨工具通用標準，全域要查各自官方文件，不會誤以為所有工具都用 `~/.codex/AGENTS.md`。
- 完成安裝後可即時測試指令是否生效（觸發多檔任務看五區段全圖）。
- 熟悉終端機的用戶可於進階提示段看到環境變數覆蓋與覆寫檔等細節，不熟悉的用戶可略過不影響使用。

### 新用戶

直接照 root README 第四節或 02 README 第五節步驟安裝。

## 四、治理層教訓（記錄入 changelog 作 audit trail）

v0.6.0 release 時，AI 寫 OpenAI Codex 路徑 `~/.codex/AGENTS.md` 屬憑記憶推斷，未經官方文件驗證，違反本 prompt 自身「先讀後判」+「外部平台必查官方文件」兩條核心規則。用戶要求驗證後，查 OpenAI 官方文件 + AGENTS.md 標準 spec + Claude Code 官方文件確認路徑大致正確，但補出兩項漏寫：環境變數覆蓋與 `AGENTS.override.md` 覆寫優先級，並修正將 Amp / Cursor / Factory / Google Jules 與 Codex 混為一段的 path hardcode 誤導。

教訓：寫任何涉及外部平台、API、CLI、套件管理器路徑或設定的內容前，必先取得官方文件，記錄基礎來源與審閱日期；不憑記憶或同類前例推斷。同類事件已於 v0.5.1 hotfix 記錄一次（主標題仍 hardcode "Cowork" 同跨工具通用聲明矛盾），本次再次發生屬同一討論串內第三次 QC 漏，按本 prompt 規則「同一討論串內重犯，升級為使用者明示介入」處理。

未來 release QC 應加：**寫任何外部路徑或 API 端點前，先 WebSearch 官方文件確認；記錄基礎來源 URL 與審閱日期**——屬機器可驗收的事實核對檢查。
