# v1.1.0 — Shorter, clearer safety-aware work

**Release date**: 2026-09-05

**One-line conclusion**: v1.1.0 consolidates repeated rules so an agent can more clearly continue safe work, block only the affected part, and present answers in a consistent, usable format.

---

## 1. What this gives you

- Both complete language versions are shorter than the pre-work baseline, reducing the burden of reading and maintaining the instruction.
- Authorized, safe work can continue; a missing source blocks only decisions or actions that depend on it, rather than unrelated safe work.
- Existing option labels and mappings stay stable, trade-offs are shown once, and recommendations and next actions are easier to scan.
- Preparation work such as backup, restoration, and trials must verify its own target, capability, and necessary conditions; it is not executable merely because it is called preparation.
- Task anchoring, source coverage, partial blockers, authorization continuity, failure recovery, and acceptance boundaries remain in place.

## 2. Should you update

- **Recommended**: users on v1.0.1, or anyone who wants fewer repeated confirmations, unnecessary stops, and confusing answer layouts during complex work.
- **May wait**: users who have v1.0.1 fixed in a controlled environment and do not need these workflow or answer-experience improvements yet.

## 3. How to use it

1. Choose one language and copy the corresponding complete v1.1.0 instruction.
2. Replace v1.0.1 in your agent tool with v1.1.0, then start a new task.
3. Begin with a small, low-risk task whose result can be read back to confirm that the new instruction is loaded.

Complete instructions:

- [Traditional Chinese Prompt 02](../../prompts/02-claude-code-meta-instruction/prompt.md)
- [English Prompt 02](../../prompts/02-claude-code-meta-instruction/prompt.en.md)

## 4. Known limitations

- The instruction does not replace platform permissions, sandboxes, tool limits, version control, or backups.
- This release is supported by bilingual source review, direct counterexamples, documentation alignment, and structural read-back. It does not claim that every model, tool, or real project has been comprehensively measured for speed or behavior.
- High-risk, irreversible, and external actions still follow the tool's and user's authorization rules.
