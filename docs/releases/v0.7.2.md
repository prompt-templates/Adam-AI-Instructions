# v0.7.2 — 按工具名稱選版本

**發布日期**：2026-07-06

**一句話結論**：這版讓讀者不用猜「對話型」或「代理式」是什麼，打開 README 就可以直接按工具名稱選版本。

---

## 一、這版對你有什麼用

如果你不熟悉 AI 工具分類，這版會更容易開始使用。

- 使用 ChatGPT、Claude、Claude Cowork 時，直接選對話型工具版本。
- 使用 OpenAI Codex、Claude Code、Antigravity CLI、Cursor 時，直接選代理式工具版本。
- 工具不在表內時，頁面會用具體用途提示：只聊天、寫作、整理資料用 01；會碰檔案、命令、機密或發布流程用 02。
- 對話型工具版本的執行面補充已收窄；純對話、純分析、短答與創作任務不會因這段規則而增加不必要步驟。

## 二、你是否需要更新

- **建議更新**：正在使用本資料庫 README、互動指南或任一 prompt 作為新工具安裝入口的人。
- **建議更新**：使用 ChatGPT、Claude、Claude Cowork、OpenAI Codex、Claude Code、Antigravity CLI、Cursor 的人。
- **可暫不更新**：已貼入舊版且目前只做低風險短答、沒有遇到選版混亂或執行面誤觸的人。

## 三、怎樣使用

1. 打開主 README。
2. 在「先按工具名稱選」表格找到你的工具。
3. 複製對應版本的 `prompt.md` 全文，貼入該工具的自訂指令、全域指令或項目指令欄位。

## 四、已知限制

- 早期發布說明與歷史實驗頁保留當時語境，可能仍出現舊工具分類說法；目前安裝入口以主 README 與兩份 prompt README 為準。
- 未列出的工具仍需要按用途判斷：只聊天用 01；會碰檔案、命令、機密或發布流程用 02。
