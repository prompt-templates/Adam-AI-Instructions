# v0.9.3 — 單一核心更清楚，少一點流程感

**發布日期**：2026-08-01

**一句話結論**：這版保留 Prompt 02 的安全與驗收邊界，但把重複流程壓縮，令日常工作與創作任務更不容易被 AI 做得過重。

---

## 一、這版對你有什麼用

- AI 更清楚知道 Prompt 02 是一份 meta instruction，不是特定工具的安裝說明。
- 普通文件、辦公、創作和小型修改，較不容易被全圖計劃、治理審閱或持久化流程拖慢。
- README 現在明確說明這版更好支援 workplace、creative、coding agent、governance 和反證審閱五類情境。
- 中文與英文互動指南改用 GitHub Pages 連結，並移除固定工具入口表，避免瀏覽器打開時只看到原始 HTML 或誤會必須使用某個入口檔。
- 選項、受阻和可執行計劃仍保留固定閱讀格式；emoji、推薦選項與風險提示不是裝飾，而是幫你快速判斷。
- 安全底線仍保留：外部寫入、發布、推送、刪除、權限、費用及其他不可逆操作仍須獨立明確授權。
- 「逐行驗」現在明確等於行語義驗收，不能用段落檢查、關鍵字搜尋或抽樣代替。

## 二、你是否需要更新

- **建議更新**：你正在使用 v0.9.2，並希望 AI 在保留安全邊界下更快處理一般工作、創作、文件修補或小型專案任務。
- **可暫不更新**：你目前只在高風險發布或嚴格治理任務中使用 Prompt 02，且不介意較厚的流程文字。

## 三、怎樣使用

1. 開啟 [使用說明](https://github.com/prompt-templates/Adam-AI-Instructions/blob/main/prompts/02-claude-code-meta-instruction/README.md)，選擇繁中或英文版本。
2. 用 v0.9.3 完整指令取代你正在使用的 Prompt 02，然後開一個新任務。
3. 先用一個小型真實任務測試，例如整理文件、修正一處文字，或要求 AI 逐行語義驗收一小段規則。

## 四、已知限制

- 本次主要是 prompt 結構與語義壓縮；尚未累積跨模型真實使用統計。
- 這份指令仍不取代工具本身的權限、沙盒、版本控制、備份或你的最後確認。
