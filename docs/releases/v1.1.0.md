# v1.1.0 — 更短、更清楚地完成安全工作

**發布日期**：2026-09-05

**一句話結論**：v1.1.0 合併重複規則，讓 Agent 更容易分辨何時繼續安全工作、何時只阻擋受影響部分，以及怎樣用清楚一致的格式交付答案。

---

## 一、這版對你有什麼用

- 完整中英文指令都比修改前基準短，閱讀與長期套用的負擔較低。
- 已獲授權且安全的工作可以繼續；缺少來源只會阻擋依賴該來源的判斷或動作，不會令無關的安全工作一併停下。
- 選項會保留原有標識與對應，取捨只呈現一次，推薦和下一步更容易掃讀。
- 備份、恢復、試行等準備工作也必須核實自身的目標、能力和必要條件，不會因為叫作「準備」便自動被稱為可執行。
- 任務錨定、真源覆蓋、局部受阻、授權延續、失敗恢復及驗收界線仍然保留。

## 二、你是否需要更新

- **建議更新**：正在使用 v1.0.1，或希望 Agent 在複雜工作中減少重複確認、無故停工及答案格式混亂的使用者。
- **可暫不更新**：已經把 v1.0.1 固定在受控環境，而且目前沒有上述工作流程或答案體驗需要改善的使用者。

## 三、怎樣使用

1. 只選擇一種語言，複製對應的完整 v1.1.0 指令。
2. 在你的 Agent 工具中，以 v1.1.0 取代原來的 v1.0.1 指令，然後開啟新任務。
3. 先用一個低風險、可讀回的小工作確認工具已載入新指令。

## 四、已知限制

- 指令本身不取代平台權限、沙盒、工具限制、版本控制或備份。
- 這次版本的完成依據是雙語正文、來源語義、直接反例、文件對齊及結構讀回；沒有宣稱所有模型、工具或真實專案的速度與行為都已全面量測。
- 高風險、不可逆或外部操作仍須按工具與使用者授權流程處理。
