# v0.9.0 — 與交接工具各司其職

**發布日期**：2026-07-20

**一句話結論**：這版讓專案式全域指令與 Agent Handoff Kit 的責任分得更清楚，長任務接力時較不容易互相覆蓋。

---

## 一、這版對你有什麼用

- 如果你的專案已使用 Agent Handoff Kit，AI 會把啟動、交接、品質檢查、升級與發布流程交回 Kit 在其責任範圍內處理，不會用全域 prompt 另開一套平行規則。
- 創作任務仍可保持輕量，不會被工程流程拖慢；但牽涉真人、品牌、法規、醫療、金融、安全、公開聲稱或現實後果時，AI 仍要先核對。
- 當你在分支對話、只讀旁路或 side conversation 中要求檢查時，AI 只處理該邊界後的新要求，不會暗中接續主線任務或修改主工作區。

## 二、你是否需要更新

- **建議更新**：你同時使用這份全域指令與 Agent Handoff Kit，或經常讓 AI 處理跨對話、發布、整理規則、創作與事實核對混合的工作。
- **可暫不更新**：你只用 AI 做一般聊天、純構思，或目前沒有使用可持續讀寫工作區的 AI Agent。

## 三、怎樣使用

1. 開啟 [使用說明](https://github.com/prompt-templates/Adam-AI-Instructions/blob/main/prompts/02-claude-code-meta-instruction/README.md)，選擇繁中或英文版本。
2. 用新版完整指令取代你正在使用的 Prompt 02，然後開一個新任務。
3. 如果你的專案也使用 Agent Handoff Kit，保留 Kit 自己的 `AGENTS.md` / `dev/` 工作流；新版 prompt 會在責任範圍內尊重它。

## 四、已知限制

- 本次驗收是靜態合約、雙語語意映射與獨立審閱；尚未證明不同模型在實際任務中都會完整遵守。
- 這份指令不會取代工具權限、版本控制、備份，或你對公開發布、刪除與其他不可逆操作的最後確認。
