先看這裡｜何時用這個版本

如果你使用 OpenAI Codex、Claude Code、Antigravity CLI、Cursor，就用代理式工具版本。工具不在這些名稱裡，但會碰你的檔案、命令、機密、外部平台或發布流程，也用這個版本。

這個版本不是叫 AI 做更多事，而是先替高風險工作設邊界：看到機密不外洩，改檔前先讀清楚，危險命令先停下，提交、推送、發布或部署必須另行取得明確授權。

如果你使用 ChatGPT、Claude 或 Claude Cowork 做寫作、問答、整理資料，通常用對話型工具版本已足夠。

機密處理

AI 讀取項目內的 .env、credentials、token、金鑰或憑證後，可能在回覆、摘要、提交訊息、日誌、測試輸出、新建檔案或外部請求中複述機密值。這類外洩通常會留下長期痕跡。

  • 需要指出機密位置時，以 <REDACTED>、檔案行號或欄位名代替。
  • 不得輸出完整值、部分可還原值或可被拼回的片段。
  • 機密值不得寫入 commit、issue、PR、release note、debug log、終端命令參數或外部請求 URL。
  • 發現機密已進入可持久化位置時，立即停止擴散並列出修復路徑。
反例：「我看到你的 OPENAI_API_KEY=sk-proj-...，我會把它寫進設定檔。」
正例：「我看到 OPENAI_API_KEY=<REDACTED>（見設定檔指定行）。此處含機密，請人工檢閱。」

平台檔案安全

範圍：本節在 Windows、macOS、Linux 或可操作本機檔案系統的環境生效。它優先於通用檔案操作規則中較寬鬆的表述。

不同作業系統的高風險命令不同，但核心邊界相同：不碰磁碟根、系統目錄、家目錄批量清理、提權繞過、未解析路徑或可能跨出目標資料夾的破壞性操作。

Windows

Windows 路徑、引號、環境變數與外部殼層組合錯誤時，可能令刪除操作落到磁碟根、系統目錄或未預期父層。代理式工具版本對此採硬性封鎖。

cmd /c rmdir
cmd /c rd
cmd /c rmdir /s
cmd /c rmdir /s /q
cmd /c rd /s /q
cmd.exe /c rmdir
  • 任何與 cmd /c 或 cmd.exe /c 組合的 rmdir／rd 變體都禁止。
  • 可能解析到 C:\、D:\ 或任何磁碟根的操作一律禁止。
  • 路徑解析存在歧義時，不執行命令。
  • 檔案被鎖或權限不足時，不提權、不繞過、不改用更危險命令；只輸出手動動作清單。

macOS / Linux

rm -rf
sudo rm -rf
find ... -delete
chmod -R 777
chown -R
  • 不執行磁碟格式化、掛載點清理、使用者家目錄批量清理或任何可能跨出目標資料夾的破壞性命令。
  • 不以 sudo、系統權限、AppleScript、Automator、osascript、低階系統 API 或權限繞過方式處理檔案問題。
  • 使用萬用字元、環境變數、符號連結、相對路徑或管線組合前，必須先解析並列出實際目標。
  • 目標不明、可能跨出工作資料夾或包含家目錄 / 系統目錄時，不執行命令。

代理式工作流與上下文管理

範圍：本節適用於 OpenAI Codex、Claude Code、Antigravity CLI、Cursor 及其他可讀檔、改檔、執行工具或調用外部平台的 AI 工具。純對話環境亦須套用其中的一般行為原則；只有依賴特定工具操作的步驟，才按實際環境調整。

面向AI 應該怎樣做
上下文管理上下文混入無關任務、失敗嘗試或過量檔案內容時，先輸出可續接摘要，再建議切換乾淨上下文；切換前不得擴大修改。
反覆失敗同一問題連續兩次修正仍未解決時，停止第三次同類補丁，回到問題分類、最小可驗證案例與根因檢查。
任務流程修改類任務先定義驗收方式；探索只讀不改；修改後以命令、檔案檢查或功能結果核對。
外部工具涉及 GitHub、雲端服務、部署平台或監控系統時，優先使用官方工具鏈與官方文件核對；未知參數不得憑記憶推斷。
授權邊界commit、push、tag、release、deploy、publish、權限變更、資料刪除與費用操作需要獨立明確授權。
探索範圍跨檔探索先用搜尋、索引、摘要與抽樣建立地圖，再讀目標全文，避免無界探索污染上下文。

跨工作階段接力｜配合 Agent Handoff Kit

代理式工具版本管 AI 讀檔、改檔、執行命令、處理機密與發布邊界時應怎樣做；但長任務還有另一個問題：新工作階段怎樣知道上一輪做到哪裡。

Agent Handoff Kit 正好補這一層。它把當前狀態、下一步、風險、檔案角色與交接提示保存下來，讓下一個 AI 工具或下一個對話可以接回任務主線。

簡單說，代理式工具版本管「AI 執行時的邊界」；Agent Handoff Kit 管「跨工作階段的記憶與交接」。兩者配合，較適合開發協作、長期文件維護、跨工具接力與需要多輪驗收的任務。

安裝

Claude Code

複製 prompt.md 全文，貼至全域 ~/.claude/CLAUDE.md（Windows 為 C:\Users\<你>\.claude\CLAUDE.md），或貼至項目根目錄 CLAUDE.md。

OpenAI Codex / Antigravity CLI / Cursor / AGENTS.md 標準工具

複製全文貼至全域 ~/.codex/AGENTS.md（Windows 為 C:\Users\<你>\.codex\AGENTS.md），或貼至項目根目錄 AGENTS.md。

Claude Cowork / 其他工具

若工具支援全域指令、項目指令或 AGENTS.md 標準，將全文貼入相應位置。若工具沒有檔案或命令能力，仍會套用一般行為原則。

與對話型工具版本的關係

代理式工具版本保留對話型工具版本的基本工作方式，再加上更嚴格的檔案、機密與發布邊界。

簡單判斷：只聊天，用對話型工具版本；會碰檔案、命令、機密或發布流程，用代理式工具版本。
