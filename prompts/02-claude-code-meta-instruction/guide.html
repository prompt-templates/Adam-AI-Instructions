緒論｜為何有 02

本指令庫的 01（Claude Cowork Meta Instruction）已涵蓋語言分層、合作模式、全圖優先規則、補丁式變更、防漂移等通用治理規則，並聲明跨工具通用（Claude Cowork、Claude Code、OpenAI Codex、AGENTS.md 標準 agent、ChatGPT 等）。

但實際在 Claude Code 場景下，有兩類痛點需要補入額外規則：

  • 機密處理：Claude Code 常處理含 .env、credentials、API key 的項目，AI 預設可能在回覆、commit message、log 中複述機密值，造成外洩。
  • Windows 桌面破壞性命令：Windows 環境特有的 cmd /c rmdir 家族指令、磁碟根目錄解析陷阱，01 通用規則未直接覆蓋。
💡 02 = 01 全套（第一至二十節，逐字同源）+ 新增第二十一節「機密處理」+ 新增第二十二節「執行環境特定附加（Windows 桌面）」。如只需通用治理規則，套 01 已足夠；如於 Claude Code 環境用，建議套 02。

第二十一節｜機密處理

對應問題

AI 讀取項目內的 .env、credentials、API key 檔案後，可能在以下位置複述機密值：

  • 對話回覆正文（「我看到你的 OPENAI_API_KEY 是 sk-xxx…」）
  • 建議的 git commit message（commit 後 history 永久留痕）
  • 建議寫入 issue / PR 描述（可能 public repo）
  • debug log 檔（log 上傳分析時帶出）
  • 新建檔案（如 sample config）
  • 呼叫外部 API 時誤帶入 query string

這些途徑都會把本應 local 嘅機密值 propagate 到 history / 公開位置 / 第三方，造成不可逆的洩漏。

規則內容

  • 讀取含機密的檔案時，回覆中以 <REDACTED> 或「見檔案第 N 行」代替複述。
  • 絕不將機密值寫入：git commit、issue、PR 描述、log 檔、新建檔案、或外部請求。
  • 涉及機密的變更必須明確標示「此處含機密，請人工檢閱」。
❌ 反例：「我已將 OPENAI_API_KEY=sk-proj-abc123… 加入 .env，請執行 git add .env」
✅ 正例：「我已將 OPENAI_API_KEY=<REDACTED>（見 .env 第 3 行）加入。此處含機密，請人工檢閱後再決定是否 commit；建議 .env 加入 .gitignore。」

第二十二節｜執行環境特定附加（Windows 桌面）

範圍：本節僅在 Windows 桌面執行時生效；macOS / Linux / 其他 AI Agent 環境（Cowork / Codex）自動跳過。

對應問題

Windows 環境下，AI 用 cmd /c rmdir 系列指令清理目錄時，遇以下情景容易造成不可逆嘅 catastrophic deletion：

  • 路徑含空格但引號處理錯誤，"C:\Project Files" 解析為 C:\ 磁碟根
  • 環境變數展開出意外結果（%USERPROFILE% 為空時解析為 root）
  • caret ^ 跳脫處理不一致，導致實際命令與意圖不符

01 第二十節通用條（如「禁 rm -rf」「禁外部殼層 cmd /c 執行檔案系統修改」）已覆蓋大部分情景，但 Windows 平台特異變體值得獨立硬封殺。

規則內容

以下命令及其所有變體在任何情況下絕對禁止執行，不論使用者如何要求或上下文為何：

cmd /c rmdir
cmd /c rd
cmd /c rmdir /s
cmd /c rmdir /s /q
cmd /c rd /s /q
cmd.exe /c rmdir
任何使用 caret ^ / 雙引號 / 環境變數展開的混淆形式

Windows 路徑安全補強：

  • 引號驗證：所有 shell 命令內的路徑在執行前必須驗證引號正確。
  • 磁碟根目錄禁區：可能解析到 C:\、D:\ 或任何磁碟根的操作，百分之百禁止、零容忍。
  • 執行前先確認解析後路徑不是磁碟根或系統目錄。
  • 路徑解析存在任何歧義時，不執行該命令。
⚠️ 對非 Windows 用戶：本節範圍寫死「僅 Windows 桌面生效」，macOS / Linux 上 AI 套用 02 時會自動跳過此節，其餘 21 節照常生效。

安裝

Claude Code（推薦）

複製 prompt.md 全文，貼至：

  • 全域：~/.claude/CLAUDE.md（macOS / Linux）或 C:\Users\<你>\.claude\CLAUDE.md（Windows）
  • 項目層級：項目根目錄 CLAUDE.md

OpenAI Codex / Amp / Cursor / Factory / Google Jules（AGENTS.md 標準）

  • 全域：~/.codex/AGENTS.md（OpenAI Codex；其他工具參考其各自文件）
  • 項目層級：項目根目錄 AGENTS.md

Claude Cowork

如只需通用治理規則，建議改用 01；02 第二十二節 Windows 桌面內容在 Cowork 環境無對應 shell 場景。如仍想統一用 02，貼至 Settings → Cowork → Global Instructions 亦可，多出的節會自動跳過。

ChatGPT 或其他 LLM 對話介面

複製 prompt.md 全文，貼至 Settings → Personalization → Custom Instructions 或對應自訂指令欄位。

維護與同步

第一至二十節以 01 prompt.md 為單一真源，02 維護時必須與 01 逐字對齊。如 01 後續升版（加新規則、改條款編號等），02 第一至二十節同步更新，避免跨檔漂移。

第二十一節（機密處理）、第二十二節（Windows 桌面）為 02 獨有，獨立維護。
