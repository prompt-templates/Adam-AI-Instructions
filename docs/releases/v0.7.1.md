# v0.7.1 — Hotfix：root README + guide.html 對齊新節數 + 勝出版本正式命名

**發布日期**：2026-05-23
**主旨**：修補 v0.7.0 release 後發現的三項漏洞：root README 第五節 02 行仍引用舊節號「第二十二節」；prompts/01 與 prompts/02 嘅互動指南 guide.html 仍含大量舊節號（SVG 標籤、h2 標題、正文引用）；勝出版本一直用實驗代號「中度瘦身版 B」對外溝通，非技術讀者難分辨。本 hotfix 一氣呵成處理。

---

## 一、這次更新解決什麼

### 漏洞一：root README 第五節 02 行節號未同步

v0.7.0 嘅批量替換腳本只覆蓋 `prompts/01/README.md` 同 `prompts/02/README.md`，**漏掉 root README.md**。索引表第 02 行「適用工具」欄仍寫「第二十二節 Windows 桌面附加為條件式生效」，與新編號（第十四節）不一致。讀者按此引用查 prompt 02 將找不到對應節。

### 漏洞二：guide.html 兩檔仍含舊節號

`prompts/02-claude-code-meta-instruction/guide.html` 含約 15 處舊節號引用：

- SVG 內嵌節數標籤（7 處）：第一節 語言分層／第三節 全圖優先規則／第十二節 治理改動先審核／第十三節 補丁式變更／第十九節 防漂移／第二十節 執行環境補充／→ 02 第一至二十節 同源逐字
- h2 標題（2 處）：第二十一節 機密處理／第二十二節 執行環境特定附加（Windows 桌面）
- 正文／表格引用（6 處）：第一至二十節、第二十一、二十二節、其餘 21 節、共 20 節等

`prompts/01-claude-cowork-meta-instruction/guide.html` 用「8 大組規則」高層次分組，無節號引用，但 prompt.md 結構大改後讀者打開指南時缺乏「結構已更新」嘅明示。

### 漏洞三：勝出版本一直用實驗代號「B」對外溝通

v0.7.0 release note、CHANGELOG、實驗報告中，勝出版本一直稱「中度瘦身版 B」或「B 中度」。實驗 context 中 A 保守／B 中度／C 激進是描述策略的代號，但對外溝通用「B」單字符不像版本名，非技術讀者難分辨「B 是什麼」。

### 修正

**漏洞一**：

- `README.md` 第 109 行：「第二十二節 Windows 桌面附加為條件式生效」改為「第十四節 Windows 桌面附加為條件式生效」。第 127 行 v0.6.0 歷史紀錄保留原節號（屬發佈當時事實）。

**漏洞二**：

- `prompts/02/guide.html`：SVG 節數標籤按 B 版重編並更新節名（第一節 語言與語體／第四節 全圖優先規則／第八節 治理改動先審核／第九節 變更交付：補丁式／第十節 防漂移與用語紀律／第十二節 執行環境補充）；h2 標題（第十三節 機密處理／第十四節 執行環境特定附加）；正文／表格全部按新編號（第一至十二節／第十三、十四節／其餘 13 節／共 12 節）。
- `prompts/01/guide.html`：在 `<main>` 標籤前插入「v0.7.0 結構更新」提示 banner，告知讀者 prompt.md 已由 20 節整合為 12 節，並指向 2026-05-23 瘦身實驗報告。本指南按主題的「8 大組規則」分組仍完全對應新結構，可繼續使用。

**漏洞三**：

- 為勝出版本確立正式名稱：「**v0.7.0 — 12-節結構整合版**」（簡稱「12-節結構整合版」或「v0.7.0 結構整合版」）。
- 同步更新以下檔案中嘅單一描述：
  - `docs/experiments/2026-05-23-pruning-experiment/v_b_moderate.md` 標題
  - `docs/experiments/2026-05-23-pruning-experiment/README.md` 結果說明、檔案索引
  - `docs/experiments/2026-05-23-pruning-experiment/comparison_report.md` 勝出宣告
  - `docs/releases/v0.7.0.md` 修正章標題與正文
  - `CHANGELOG.md` v0.7.0 條目
- A／B／C 三檔對照表嘅欄頭保留原名（描述實驗策略幅度，是學術用語，非版本名）。

## 二、命名規約（自此確立）

| 場景 | 用法 |
|---|---|
| Release / 版本識別 | `v0.7.0` |
| 對外溝通正式名稱 | `v0.7.0 — 12-節結構整合版` |
| 簡稱（自然語境） | `12-節結構整合版` 或 `v0.7.0 結構整合版` |
| 實驗報告中對照（保留） | `A 保守 / B 中度 / C 激進`（策略代號，描述瘦身幅度） |
| 不再使用 | `B 版`、`中度瘦身版 B`（除非明確標「實驗代號 B 中度」） |

## 三、你會在何時感受到變化

- 開 root README 第五節索引表，02 行嘅節號引用與 prompt 02 本身一致，按引用查 prompt 02 即可找到「第十四節」
- 開 prompts/02/guide.html，所有節數標籤、h2、正文都與最新 prompt.md 一致，無誤導
- 開 prompts/01/guide.html，頂部有 v0.7.0 結構更新提示 banner，知道 prompt.md 已升版而本指南仍可用
- 看 release note、實驗報告、CHANGELOG 嘅版本名，明確是「v0.7.0 — 12-節結構整合版」而非「B 版」這種實驗代號

---

## 四、如何升級

無 prompt.md 內容變動，套用 v0.7.0 嘅用戶毋須重新貼入。直接 pull repo 最新版本查 README / guide.html 即可。

## 五、治理層教訓

v0.7.0 release 前嘅批量節號替換腳本只覆蓋 prompts/ 下嘅 README，**未覆蓋 root README 與 guide.html**。屬「修改前最低閱讀覆蓋」未做足 — 應該先列出全 repo 對舊節號的所有引用，再做替換；不應預設只動 prompts/ 即夠。

亦：guide.html 是視覺指南，含 SVG 嵌入節數標籤，等同雙處同步源。長遠應該由腳本根據 prompt.md 自動生成 SVG 節數標籤，或將節數從 SVG 標籤抽離為註腳；現狀仍是漂移源，已記入 dev/SESSION_LOG.md 等下次重構處理。

「B 版」對外溝通漏洞屬命名規約缺失：實驗代號（A／B／C）應與正式版本名（v0.7.0）分開，前者描述策略幅度只在實驗內使用，後者用於對外。已在本 hotfix 確立規約見第二節「命名規約」。
