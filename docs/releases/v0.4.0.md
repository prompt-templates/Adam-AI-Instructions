# v0.4.0 — 規則結構大整理，新增兩條上位核心規則

**發布日期**：2026-05-15
**主旨**：將指令由「【】+ 漢字序號」轉為標準 Markdown 階層；把「先驗證再判斷」「治理改動先審核」兩類核心精神，從散佈於多處嘅子規則升為上位核心章節，方便引用與長期維護。

---

## 一、這次更新解決什麼

### 痛點一：章節結構唔似標準 Markdown 文件

**之前是這樣**：

v0.3.0 用「【語言分層｜最高優先規則】」「【全圖優先規則｜核心規則】」呢類括號標題 + 漢字序號做章節分隔。揭開 prompt.md 一望全係齊頭文字，要逐段眼掃先揾到二級／三級結構；複製去 Notion、Obsidian、GitHub 時 render 唔出階層；引用某條規則時要打全標題先唯一指認。

**現在會變成這樣**：

整份指令轉為標準 Markdown 二級／三級階層：

- 一級主標題：`# Claude Cowork 全域指令`
- 個人偏好獨立小節：`## 個人偏好`
- 規則章節：`## 一、語言分層`、`## 二、合作模式`、…、`## 二十、Cowork 專屬補充`（中文漢字序號二級標題，順序固定）
- 子章節：`### 使用者輸出層`、`### 觸發條件`、`#### 一、終點畫面` 呢類三級／四級

GitHub、Notion、Obsidian、VS Code preview 全部 render 出清晰階層；用標準 Markdown 大綱工具可一鍵生成 TOC。

### 痛點二：「先驗證再判斷」嘅精神散佈於三個位置

**之前是這樣**：

v0.3.0 入面，關於「核對事實」「禁止憑記憶」「禁止用代理訊號代替全貌」呢類精神散佈於：

- 獨立章節「【事實核對（非創作）】」
- 全圖優先規則內嵌段「6 項計劃自檢」
- Cowork 補充 11C「禁止憑記憶推斷」

三處都係 partial coverage，冇統一上位定義。新規則一加就容易撞舊句，AI 引用時 cite 唔到一個 canonical 位置，long-term 維護越加越亂。

**現在會變成這樣**：

新增「## 十一、先讀後判（核心規則）」上位章節，把呢類精神收歸統一上位定義；其他位置只引用，不重複。內容包括：

- 可驗證事實（日期、數字、法規、人名、公司、報價、引用）先核對再作答
- 禁止用代理訊號代替全貌（版本控制改動時間、檔頭一句、搜尋命中次數、狀態檔自述不可當作「內容是否最新／正確／過期」嘅判斷依據）
- 禁止憑記憶推斷項目結構、檔案內容、規則細節、外部平台行為
- 禁止用產出代替思考（未想清楚問題本質前，不可用「先提一個方案／先列選擇題／先交一份東西」迴避思考）
- 用戶質疑視為「我此刻可能正用捷徑」嘅信號（必停下、真驗證）
- 由基礎做起、逐步推進、每步驗證穩固才繼續
- 未能核對 = 未核實（不等同未適用）
- 違反任何一條：當次判斷視為未成立，回到真讀／真驗證重做

呢類精神全部喺一個位置，AI 引用統一指 prompt.md 第十一節。

### 痛點三：「治理改動先審核」嘅 sub-letter 編號難引用

**之前是這樣**：

v0.3.0 嘅「治理層計劃自檢機制」「強制只讀審核」散佈於：

- 全圖優先規則內嵌嘅 6 項自檢段
- Cowork 補充 11D（治理計劃自檢）
- Cowork 補充 11E（資料未讀夠只能交審核計劃）
- Cowork 補充 14A（規劃階段不得當「看似可執行」係「已審核」）

四處要拼合才見全貌；sub-letter 編號（11D / 11E / 14A）唔連續，新增時要再揾下一個 sub-letter。

**現在會變成這樣**：

新增「## 十二、治理改動先審核（核心規則）」上位章節，將四個位置嘅內容收歸統一上位定義；並補入「規劃階段不得把『看似可執行』當成『已審核』」一句作 anti-shortcut 紅線。Cowork 補充 11A-11E、14A 等 sub-letter 編號全部退役，Cowork 補充改用 sequential 1-22 編號。

## 二、你會在何時感受到變化

- 當你揭開 prompt.md 時——章節階層一眼睇晒，唔再要逐段眼掃。
- 當你 cite 規則時——可直接引「第十一節 先讀後判」「第十二節 治理改動先審核」「第十九節 防漂移」等標準二級標題，唔再要打全括號標題。
- 當 AI 處理任何「先讀後判」場景時——會引一個統一上位章節，不再喺三個位置撞口徑。
- 當 AI 處理治理層任務嘅計劃自檢、強制只讀審核時——由獨立上位章節定義，新規則加入時更易合併、退役舊句。
- 當你引用 Cowork 補充第幾條時——編號連續（1-22），無 sub-letter 跳號。

### 未套用過的用戶

請按主 [README](https://github.com/prompt-templates/Adam-AI-Instructions/blob/main/README.md) 第四節「使用方式」操作。
